## 📖 আক্রমণ ও প্রতিরক্ষার ব্যাকগ্রাউন্ড (Case Study)

আপনার দেওয়া সোর্স ভিডিও অনুযায়ী, আক্রমণকারীরা টেলিগ্রামের একটি ডিডক্স বুটার বট (`Kaal ☠️` / `@TUFAN_XXD`) দিয়ে লাইভের মিডিয়া পোর্টে আক্রমণ চালায়:
```bash
./attack 91.108.17.35 32003 60
```
এর ফলে টেলিগ্রামের অডিও/ভিডিও পোর্ট ক্র্যাশ করে এবং পর্দায় এরর আসে:
> **Video Chat**  
> *An error occurred: `GROUPCALL_INVALID`*

### 💡 আমাদের ডিফেন্স বট কীভাবে এটিকে ১০০% ব্যর্থ করে?
1. **চ্যানেল ১০০% পাবলিক থাকবে:** চ্যানেলকে প্রাইভেট করা বা অ্যাপ্রুভাল সিস্টেম চালু করার কোনো প্রয়োজন নেই।
2. **জিরো-ডাউনটাইম পোর্ট রিরুট (<৩০০ মিলিসেকেন্ড):** আক্রমণকারীর বুটার ৬০ সেকেন্ডের জন্য নির্দিষ্ট পোর্ট ও আইপিতে লক হয়ে যায়। আমাদের সেন্টিনেল বট লাইভ ড্রপ হওয়ার ৩০০ মিলিসেকেন্ডের মধ্যে নতুন আইপি ও সম্পূর্ণ নতুন পোর্টে লাইভ রিস্টার্ট করে দেয়।
3. **আক্রমণকারীর ৬০ সেকেন্ড নষ্ট:** আক্রমণকারীর বুটার ৬০ সেকেন্ড ধরে পুরোনো ডেড পোর্টে আবর্জনা ট্র্যাফিক পাঠাতে থাকে, অথচ আপনার দর্শকরা মুহূর্তেই নতুন পোর্টে সংযুক্ত হয়ে যায় এবং লাইভ নিরবচ্ছিন্নভাবে চলতে থাকে।
4. **স্নিফার হান্টার:** লাইভে কোনো অবৈধ ইউজারবট ঢুকে আইপি-পোর্ট চুরি করার চেষ্টা করলে তাদের তাৎক্ষণিক মিউট ও নিষ্ক্রিয় করা হয়।

## 🚀 সেটআপ ও রান করার নিয়ম (Step-by-Step)

### ধাপ ১: টেলিগ্রাম এপিআই কী সংগ্রহ
1. [my.telegram.org](https://my.telegram.org) এ আপনার টেলিগ্রাম অ্যাকাউন্ট দিয়ে লগইন করুন।
2. **API development tools** এ ক্লিক করুন।
3. যেকোনো অ্যাপ নাম দিয়ে **`api_id`** এবং **`api_hash`** কপি করুন।

### ধাপ ২: .env ফাইল কনফিগারেশন
প্রজেক্ট ফোল্ডারে থাকা `.env` ফাইলে আপনার তথ্যগুলো বসান:
```env
# my.telegram.org থেকে নেওয়া তথ্য
API_ID=12345678
API_HASH=abcdef1234567890abcdef1234567890

# যে অ্যাকাউন্টে চ্যানেলের Ownership বা Admin রাইট আছে
PHONE_NUMBER=+8801XXXXXXXXX

# আপনার পাবলিক চ্যানেলের ইউজারনেম (বা আইডি)
TARGET_CHANNEL=@your_public_channel

# লাইভ টাইটেল
LIVE_STREAM_TITLE=🔴 লাইভ স্ট্রিম (সুরক্ষিত ও সচল)
```

### ধাপ ৩: এক ক্লিকে বট চালু করুন
টার্মিনালে যান এবং রান করুন:
```bash
cd "/Users/appletalha/Desktop/Future Project .promt💀/telegram-anti-ddos-guard"
./start.sh
```
*(প্রথমবার রান করার সময় আপনার টেলিগ্রাম ফোনে পাঠানো ৫ সংখ্যার ওটিপি কোডটি টার্মিনালে দিতে হবে, এরপর সেশনটি স্বয়ংক্রিয়ভাবে সেভ হয়ে যাবে।)*
